# Synapse workspace

The active native app is `synapse-mobile`; read its `AGENTS.md` before changing it. Preserve the separate `synapse` prototype and existing uncommitted work.

Follow the global orchestration policy. Project configuration is `synapse-mobile/tools/agent-orchestration/config.json`; existing commands in that directory forward to the shared installation, with Scrolls as the Git root. See its README for the Synapse scope. Feed, personalization, network/cache contracts, migrations and visual/architectural decisions stay with the main agent. Delegation never authorizes changes to the protected prototype runtime.
