# Lume workspace

The native app lives in `lume/`; read its `AGENTS.md` before changing it. Preserve existing uncommitted work.

Follow the global orchestration policy. Project configuration is `lume/tools/agent-orchestration/config.json`; existing commands in that directory forward to the shared installation, with this repository as the Git root. See its README for the Lume scope. Feed, personalization, network/cache contracts, migrations and visual/architectural decisions stay with the main agent.
