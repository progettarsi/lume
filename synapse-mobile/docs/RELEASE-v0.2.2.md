Lume v0.2.2 migliora la reattività di navigazione, categorie, lettore e salvataggi.

- Corrette le aree di tocco della navbar e il contenimento delle schermate.
- Il feed mantiene una scheda leggibile quando gli avanzamenti superano il caricamento delle pagine; rifornimento locale anticipato e riallineamento dopo la riduzione del feed.
- Corrette apertura e chiusura degli articoli, intercettazione dei tocchi e icona del segnalibro.
- Ridotti ricalcoli della riserva, ordinamenti delle categorie e normalizzazioni ripetute all'avvio.
- Rafforzati recupero dei dati locali, gestione errori e compatibilità con salvataggi, cronologia e preferenze esistenti.

**Download:** `Lume-0.2.2.apk` è un unico APK universale, con ARM 32 bit (`armeabi-v7a`), ARM 64 bit (`arm64-v8a`), Intel 32 bit (`x86`) e Intel 64 bit (`x86_64`). Richiede Android 7.0 / API 24 o successivo. Non occorre scegliere un file in base all'architettura.

**Aggiornamento:** versione 0.2.2, build 24, pacchetto `app.synapse.reader`. Installare sopra la versione precedente per conservare i dati; firma di aggiornamento preservata. Il file SHA-256 allegato permette di verificare il download.

**Verifiche:** TypeScript, 314 test automatici, export Android e compilazione release.
