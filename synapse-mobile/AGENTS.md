# Synapse native app

- Android automation: use the persistent `Lume_API_36` emulator (`emulator-5580`) by default for authorized Lume device tests. `scripts/adb-emulator.ps1 <adb arguments>` automatically boots it on demand and explicitly targets that emulator; never implicitly select a USB phone. `scripts/start-emulator.ps1` prepares the session for other Android tools. See `docs/ANDROID-EMULATOR.md`. Setup/start alone never authorizes running tests, building, installing or opening the app; honor the current user's scope. Do not wipe the AVD data without explicit authorization.

- React Native / Expo, Android first with iOS-compatible application code. This is separate from the approved `../synapse` browser prototype; do not alter its protected runtime.
- Lume palette revised 2026-10-14 (olive and cream, warm charcoal dark background #1B1915), Newsreader headings, local Google Sans Flex body/controls; Newsreader ExtraBold Italic for lowercase «lume»; Newsreader Medium 500 upright for the onboarding welcome heading. Shared tokens, primitives and controls live in src/design-system; theme.ts and Atoms.tsx are compatibility exports. Follow docs/DESIGN-SYSTEM.md for the current palette; it supersedes the colors in docs/LUME-04-IMPLEMENTATION-HANDOFF.md. No article illustrations or account.
- All categories in a horizontally scrolling rail, fading at the right edge; no drag or long-press reordering (removed at user request after device testing). Per te stays first.
- Mirror the rail's 32 px right fade at the left edge. Left opacity follows horizontal scroll displacement smoothly on the UI thread, stays visible while categories extend offscreen to the left, and returns to zero at the start without covering Per Te at rest. The gradient never intercepts touches.
- Settings include a persistent category auto-hide switch, enabled by default. When disabled, the Home category rail stays visible during article paging; turning it off restores an already hidden rail.
- Home has a fixed 90 px top gradient below the category rail, mirroring the bottom fade. Reveal it smoothly only during upward article paging, follow interrupted/reversed gestures and spring settlement, and leave resting articles fully unobscured. Support both category auto-hide settings and themes.
- Feed publishes the first available response quickly, then progressively builds a persistent reserve of 20–30 useful previews during use. Refill ahead of exhaustion; no blocking bulk synchronization at launch. Keep explicit cache/request budgets and protect saved, active and useful reserve articles. Reader requests preempt background downloads. Extended text is offline only when actually downloaded.
- Wikipedia and Wikivoyage Italian public APIs directly (cultural sections only for Wikivoyage), with attribution, polite retries, cancellation and no paid backend. Online search ranks relevance, not cache presence. Shuffle online retrieves a new random Wikipedia article; offline uses the cache.
- General-audience text selection. Optional free-quota AI requires a user key, must fail back to original extracts, never enable billing or embed a key. Personalized ranking is local and implemented: interests from voluntary opens and reversible saves, with interaction-order recent memory and stable future-feed refresh. Never use reading duration, exposure, comprehension estimates or adaptive content length. Preserve versioned profiles, atomic migration backups and bookmark contributions. Technical Gemini preparation timers remain independent.
- Native gestures and animations must remain interruptible, including reversing reader transitions. No timers locking input. Respect reduced motion and accessibility.
- Visual polish and coherent, fluid motion are a primary product requirement. Keep text in its final layout during gestures; reveal via clipping, opacity and transforms, never growing text containers or scaling labels. Coordinate insertion/removal with neighbouring rows and verify motion on device, not only static endpoints. Preserve the established row appearance; do not add a visible removal button beside saved articles.
- Launcher/adaptive icons and onboarding use assets/logo-lume.svg. Preserve its supplied book/star paths and proportions.
- Typecheck, test feed/network/cache contracts and export Android bundle before handoff. Clearly distinguish these from an actual APK/device verification.

- Discovery editions keep complete 40–80-word briefs and explicit continuations. The 150 bundled, source-backed editions have automatic selection checks bound to exact text/provenance; never rewrite verified editions with Gemini. Catalogue and dynamic reserve remain separate. See docs/DISCOVERY-RELEASE.md.

- Signing material in .credentials (including signing.json and private backup folders) must never be committed, printed, deleted or regenerated without explicit user authorization. Preserve both keystore and password. The key was replaced with user consent on 2026-10-14 for a clean v0.2.1 installation; future updates must retain that new key.
