# Lordicon System Solid

[Animated icons by Lordicon.com](https://lordicon.com/)

- `home.json`: [System Solid 63 Home](https://lordicon.com/icons/system/solid/63-home), `hover-pinch`.
- `avatar.json`: [System Solid 21 Avatar](https://lordicon.com/icons/system/solid/21-avatar), `hover-pinch`.

Downloaded from the official editor as Lottie JSON on 2026-10-16. Both icon pages identify these assets as FREE. The upstream Home JSON internally retains the name `system-solid-41-home`; its download and catalogue identity is 63 Home.

Use only as part of the application, not as a standalone icon pack. Keep attribution in Settings → Informazioni and the project README, and acknowledge Lordicon in any future store listing. [Attribution requirements](https://lordicon.com/docs/license/attribution).

The application recolors the monochrome fills for the current theme and plays the supplied one-second animation once. Assets are bundled locally and require no network access.
